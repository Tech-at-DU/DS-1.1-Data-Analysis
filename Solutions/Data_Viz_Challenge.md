# Data Visualization Challenge — Solutions

Answers to the **Check Your Understanding** questions in [CA_lessons/Data_Viz_Challenge.md](../CA_lessons/Data_Viz_Challenge.md). Try each question yourself before reading the answer.

1. Strip the `%` character and convert the result to a numeric type, e.g. `df['Rotten Tomatoes'].str.rstrip('%').astype(float)`. Until that conversion happens, the column is text, and text can't be averaged or plotted on a numeric axis.

2. Without a stated angle, it's easy to end up with a scattershot of disconnected charts that don't build toward any conclusion — technically correct individually, but not actually telling anyone anything. Picking an angle first turns "here are some charts about movies" into an actual argument or story, which is the real skill this exercise is practicing — not just chart-making mechanics.

3. Whether the charts **connect into a coherent narrative** — a fixed answer key can check "is this number correct," but it can't check "does this set of otherwise-correct, well-made charts actually support one point, or is it just a pile of unrelated facts." That's a judgment call this project's rubric asks you to make about your own work.
