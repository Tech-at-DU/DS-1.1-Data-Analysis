# Conditional Probability — Solutions

Answers to the **Check Your Understanding** questions in [Lessons/ConditionalProbability.md](../Lessons/ConditionalProbability.md). These are not the Challenges — the Challenges are open-ended and reviewed by an instructor. Try each question yourself before reading the answer.

1. **0.4 (40%).** `4 / (4 + 6)`.

2. **Independent.** The outcome of one flip has no effect on the probability of the other — the coin has no memory.

3. **0.4.** `P(B|A) = P(A and B) / P(A) = 0.2 / 0.5 = 0.4`.

4. **False.** If two events are mutually exclusive, one happening means the other *can't* — so if A occurs, `P(B)` drops to 0. That's exactly what "dependent" means (one event's occurrence changes the other's probability). Mutually exclusive events with nonzero probability can never be independent.
